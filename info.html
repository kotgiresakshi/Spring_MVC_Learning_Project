FOLLOW A REQUEST FROM START TO FINISH

The complete Spring MVC flow.

A browser request passes through a series of Spring MVC components. Each one has a clear responsibility before the finished response returns to the browser.

REQUEST → RESPONSE

Spring MVC request flow

Follow the arrows from the browser to the server and back. The service and data layer are optional application components.

  1. 1 · REQUEST Browser

    Sends an HTTP request for a page, such as GET /books.

  2. 2 · FRONT CONTROLLER DispatcherServlet

    Receives the request and coordinates Spring MVC.

  3. 3 · FIND A HANDLER HandlerMapping

    Matches the URL and HTTP method to a Controller handler.

  4. 4 · INVOKE HANDLER HandlerAdapter

    Invokes the selected Controller method with the request data.

  5. 5 · HANDLE REQUEST Controller

    Validates input and coordinates application work.

    Optional application/data flow
    Service → Repository → Database

    Results return to the Controller to prepare the page data.

  6. 6 · PREPARE PAGE Model + logical view name

    The Controller provides page data (Model) and a view name, such as "books".

  7. 7 · RESOLVE VIEW ViewResolver

    Maps the logical view name to the configured template, such as books.html.

  8. 8 · RENDER PAGE View

    Combines the template with Model data to create the response, usually HTML.

  9. 9 · RESPONSE DispatcherServlet → Browser

    Returns the rendered page and HTTP status for the browser to display.
