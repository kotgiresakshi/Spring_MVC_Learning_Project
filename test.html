THE BUILDING BLOCKS

The main ideas

Think of an app like a helpful restaurant: each part has a clear job.

01
M

What is Spring MVC?

Spring MVC is a way to organize a web application. It separates handling requests, working with information, and showing a page so each part has a focused job.

Spring MVC

02
D

Model

The Model holds the information a page needs. For example, it might carry a person’s name or a list of products to show.

03
V

View

The View is what the visitor sees: the web page displayed in their browser. It uses information from the Model to show useful content.

04
C

Controller

The Controller receives a visitor’s request, decides what needs to happen, and prepares the information and page to send back.

05
↗

DispatcherServlet

Think of DispatcherServlet as a friendly front desk. It receives incoming web requests and sends each one to the right Controller. It then helps return the finished page to the visitor.

FROM CLICK TO PAGE

How a request flows

Here’s what happens when someone visits a page or submits a form.

  1. 1
    A visitor makes a request

    They click a link or submit a form in their browser.

  2. 2
    DispatcherServlet receives it

    The front desk gets the request and finds the right Controller.

  3. 3
    The Controller does the work

    It handles the request and gathers any information the page needs.

  4. 4
    The Model carries the information

    The Controller puts the relevant data into the Model.

  5. 5
    The View becomes a page

    The View uses the information to create a page, which is sent back to the visitor.
